# To-Do List

A simple command-line To-Do List application made with Python.

## Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Save tasks using a JSON file
* Load saved tasks when the program starts

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python todo_list.py
```

* Python

* File Handling
